Coupang Order Viewer

주문 메일을 CSV로, 공동구매 정리를 간단하게

쿠팡 주문 메일에서 배송지·수량을 뽑아 CSV로 내보내는 Windows 도구입니다. 공동구매 정리에 쓰려고 만들었어요.

Windows
WPF · .NET 8
메일 → 엑셀
수집 · 조회 · 내보내기
DPAPI
로컬 저장 정보 보호

목차 CONTENTS

01 문제 02 결정 03 결과 04 근거

01 문제 PROBLEM

공동구매 할 때마다 주문 메일을 하나하나 열어서 배송지·수량을 옮겨 적는 게 꽤 지쳤습니다. 메일 수집부터 CSV 내보내기까지 한 번에 되는 도구가 있으면 편하겠다 싶었어요.

02 결정 DECISION

MailKit으로 읽고, WPF로 보여줬어요

IMAP으로 주문 메일을 받아 파싱하고, WPF·MVVM으로 조회 화면을 짰습니다. 받은 걸 눈으로 확인한 다음 내보내는 흐름입니다.

내보내기와 로컬 보호를 같이 챙겼어요

ClosedXML로 엑셀 내보내기를 붙이고, 로컬에 남는 메일 비밀번호는 Windows DPAPI로 암호화했습니다.

03 결과 RESULT

주문 메일 수집 → 조회 → 엑셀 내보내기까지 한 Windows 앱으로 묶었어요. 손으로 하던 반복이 거의 사라졌습니다.
