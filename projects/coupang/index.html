01 문제 PROBLEM

개인 구매자의 주문 메일을 읽고 주문·배송지 정보를 따로 정리하는 반복 작업이 번거로웠습니다. 메일 수집과 정보 조회, 파일 내보내기를 이어서 처리하는 Windows 도구를 만들고자 했습니다.

02 결정 DECISION

메일 수집과 주문 정보 파싱을 연결했습니다

MailKit으로 주문 메일을 읽고 필요한 정보를 파싱했습니다. WPF·MVVM으로 주문과 배송지 정보를 확인하는 조회 화면을 구현했습니다.

내보내기와 로컬 정보 보호를 함께 구현했습니다

ClosedXML로 엑셀 내보내기를 지원해 정리한 정보를 파일로 활용할 수 있도록 했습니다. Windows DPAPI를 적용해 로컬에 저장하는 정보를 보호했습니다.

03 결과 RESULT

주문 메일 수집 → 주문·배송지 조회 → 파일 내보내기로 이어지는 Windows 데스크톱 도구를 구현했습니다. 반복적으로 따로 정리하던 과정을 하나의 도구에 구성했습니다.
