Minishell

C로 구현한 Unix 셸

명령 실행, 파이프, 리다이렉션을 직접 구현하며 Unix 프로세스와 파일 I/O를 익힌 42 프로젝트입니다.

01 문제 PROBLEM

매일 쓰는 Unix 셸을 C로 다시 짜 봐야 하는 과제였어요. 입력을 받아 명령을 돌리고, 파이프·리다이렉션으로 프로세스 입출력을 연결하는 게 핵심이었습니다.

02 결정 DECISION

입력 → 실행 흐름을 먼저 세웠어요

readline으로 입력을 받고 내장·외부 명령 실행을 붙였습니다. 사용자가 친 문자열이 실제 프로세스로 바뀌는 지점을 손으로 다뤄봤어요.

파이프와 리다이렉션으로 I/O를 꿰었어요

파이프와 리다이렉션을 짜면서 명령의 입출력이 다른 프로세스나 파일로 넘어가는 방식을 체득했습니다.

03 결과 RESULT

readline 입력, 내장·외부 명령, 파이프·리다이렉션을 지원하는 셸을 올렸어요. 명령·프로세스·I/O가 한 프로그램 안에서 어떻게 묶이는지 손으로 익힌 과정입니다.
