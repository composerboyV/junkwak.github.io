01 문제 PROBLEM

기존 분석 기능을 외부 파트너 서비스에 연동해야 했습니다. API 구현 못지않게, 요구사항·일정·문서·검증 과정을 양측이 동일한 상태로 보고 움직이도록 조율하는 역할이 핵심이었습니다.

02 결정 DECISION

AICU 쪽 전체 PM과 API 개발 겸임

파트너와 요구사항·일정·문서를 맞추고, 협력사 인증·입력 검증·OpenAPI 문서화 항목을 개발 티켓으로 분해해 양측이 동일한 산출물을 추적하도록 했습니다.

기존 모델을 FastAPI로 노출

이미 있는 분석 모델을 FastAPI로 감싸 배포한 뒤, 요청·응답과 성능을 조건별로 검증했습니다. 결과를 파트너와 공유하며 다음 작업을 조율했습니다.

03 결과 RESULT

분석 기능이 FastAPI로 노출되어 돌기 시작했고, 배포 상태에서 파트너와 결과를 맞춰 가며 연동을 이어가고 있습니다.

2026.10.07 회사 네트워크·동일 이미지 단발 시험에서 32건 동시 요청 성공, p95 3.247초를 기록했습니다 (8/16/32건 누적 56건 성공). 조건부 결과이며 운영 성공률·SLA 수치가 아닙니다.
