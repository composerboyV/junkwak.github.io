서비스별 관리자 웹

스툴케어·피칼스캐너·피칼스캐너-M의 관리자 웹과 접근 통제

세 서비스의 운영자와 의료진이 사용자 기록과 검사 사진을 다루는 관리자 웹입니다. 화면 기능만큼, 누가 어디까지 볼 수 있는지를 서버에서 확인하는 데 중점을 뒀습니다.

담당 범위
스툴케어 통합 관리자 웹과 피칼스캐너-M 의료진·관리자 웹은 새로 만들었습니다. 피칼스캐너 관리자 웹은 기존 웹을 유지보수하며 기능과 접근 통제를 추가해 안정성을 더했습니다.
중점
관리자 확인은 서버에서 하고, 조회 범위는 필요한 만큼만 열고, 조회와 내보내기는 기록으로 남깁니다.

01 배경과 목표 CONTEXT

관리자 웹은 일반 사용자 화면과 달리 여러 사람의 기록과 사진을 한꺼번에 볼 수 있습니다. 그래서 화면 기능보다 먼저, 로그인한 사람이 정말 관리자인지와 그 관리자가 어디까지 볼 수 있는지를 정해야 했습니다.

세 서비스는 서버 구성도, 쓰는 사람(운영팀, 병원 담당자, 의료진)도 다릅니다. 서비스마다 관리자 웹을 따로 두고, 접근 통제도 각 서비스에 맞게 넣었습니다.

02 세 관리자 웹 ADMIN SITES

스툴케어 · 한국·미국 통합 관리자 웹

한국과 미국 서버에 나뉜 사용자 기록, 구독 현황, 문의를 한 화면에서 조회하는 운영 웹입니다. 기록은 엑셀로, 사진은 ZIP으로 내려받을 수 있습니다. 화면 전체와, 화면이 쓰는 국가별 API 모듈(조회·로그인 확인·문의·AI 사용량)을 새로 만들었습니다. React · TypeScript · MUI · NestJS.

피칼스캐너 · 관리자 웹

기관, 사용자, 검사 기록을 조회하고 통계를 보는 운영 웹입니다. 기존 웹을 유지보수하면서 조건으로 검사 묶음을 저장하는 저장 카테고리, 사진 ZIP·엑셀 내보내기, 사용량 모니터링을 추가해 안정성을 더했습니다. Next.js · Firebase.

피칼스캐너-M · 의료진·관리자 웹

의료진이 같은 기관 참여자의 검사 이력을 보고, 관리자는 계정·기관·감사 기록을 관리하는 웹입니다. 의료기기 소프트웨어의 일부로 새로 만들었고, 사이버보안 시험의 대상에 포함됩니다.

03 보안에서 중점을 둔 것 ACCESS CONTROL

관리자인지는 서버가 확인합니다

화면에서 메뉴를 숨기는 것만으로는 막을 수 없어서, 관리자인지 아닌지는 서버가 확인합니다. 스툴케어는 한국 서버 한 곳에서 로그인을 확인하고, 미국 API는 요청마다 그 세션이 유효한지 확인한 뒤에만 응답합니다. 확인에 실패하거나 연결이 끊기면 통과시키지 않습니다. 피칼스캐너는 관리자 여부를 서버가 관리하는 권한 정보로 판단합니다. 피칼스캐너-M은 의료진 전용 로그인을 두고 역할에 따라 메뉴를 나눴습니다.

볼 수 있는 범위를 좁혔습니다

스툴케어의 기록·구독 화면은 조회만 하고, 문의 화면에서만 처리 상태와 메모를 바꿀 수 있습니다. 관리자 웹은 데이터베이스에 직접 연결하지 않고 API를 거쳐서만 데이터를 다룹니다. 피칼스캐너-M의 의료진은 같은 기관 참여자의 기록만 볼 수 있습니다.

검사 사진은 로그인한 관리자만 받습니다

검사 사진은 가장 민감한 데이터입니다. 피칼스캐너는 사진을 로그인한 관리자만 받을 수 있는 경로로 제공하고, 엑셀 내보내기에는 사진 링크 대신 파일 이름을 넣었습니다. 스툴케어는 내보내기에 건수와 용량 상한을 두고, 사진은 묶음으로 나눠 받게 했습니다.

누가 무엇을 봤는지 남깁니다

스툴케어는 누가 무엇을 조회했는지 기록으로 남깁니다. 피칼스캐너-M은 로그인 성공·실패와 검사 열람을 감사 기록으로 남기고, 한 계정에 세션을 하나만 허용하며, 오래 쓰지 않으면 자동으로 로그아웃합니다.

04 결과 RESULT

스툴케어 한국·미국 사용자 기록, 구독·쿠폰, 문의를 한 웹에서 조회하고 내려받습니다. 2026년 10월에 배포했습니다.

피칼스캐너 조건으로 묶은 검사 기록과 사진을 한 번에 내려받고, 검사 사진은 로그인한 관리자만 볼 수 있습니다.

피칼스캐너-M 의료진·관리자 웹은 앱과 함께 사이버보안 시험을 받았고, 적용 항목 30개가 모두 적합으로 나왔습니다.
