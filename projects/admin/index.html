한국·미국 통합 관리자 웹

01 문제 PROBLEM

한국·미국 서비스의 사용자와 기록을 확인하고, 구독·쿠폰·문의 업무를 처리할 운영용 웹이 필요했습니다. 한곳에서 업무를 수행하면서도 국가별 데이터는 구분해 볼 수 있어야 했습니다.

02 결정 DECISION

국가별 데이터와 운영 기능을 함께 구성했습니다

사용자와 기록 조회, 구독·쿠폰·문의 관리를 하나의 웹에 구성했습니다. 국가별 데이터를 구분해 볼 수 있도록 하고, 데이터 내보내기와 다운로드 기능을 연결했습니다.

독립적인 관리자 웹으로 배포했습니다

React·TypeScript·Vite·MUI로 운영 화면을 구현했습니다. 독립적인 관리자 웹으로 배포한 뒤 서비스 상태와 접근 확인 항목을 점검했습니다.

03 결과 RESULT

한국·미국의 사용자·기록·구독·쿠폰·문의 업무를 관리하는 웹을 구현하고 배포했습니다. 조회한 데이터를 내보내거나 다운로드할 수 있도록 운영 흐름을 연결했습니다.

2026년 10월 11일 배포 점검에서 상태·접근 확인 17개 항목이 통과했습니다. 이는 배포 확인 범위이며 전체 사용자 시나리오에 대한 종합 테스트 수는 아닙니다.
