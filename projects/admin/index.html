한국·미국 통합 관리자 웹

한국과 미국 서비스를 한곳에서 관리하는 운영 웹

한국과 미국 서비스의 사용자 기록, 구독 현황, 문의를 한곳에서 관리하는 웹입니다. 필요한 기록과 사진을 엑셀·ZIP 파일로 내려받을 수 있습니다.

담당 범위
관리자 웹 화면 전체와, 화면이 쓰는 국가별 NestJS API 모듈(조회·로그인 확인·문의·AI 사용량)을 만들었습니다.
대상 서비스
한국·미국 서버를 따로 운영하는 스툴케어
진행 형태
신규 구축 · 2026.10 배포

01 배경과 목표 CONTEXT

스툴케어는 한국과 미국 서버를 따로 운영하고, 관리자 도구도 나라별로 나뉘어 있었습니다. 사용자 한 명의 기록이나 문의를 확인하려면 두 도구를 번갈아 열어야 했습니다.

목표는 두 나라 데이터를 한 화면에서 찾되, 국가별 데이터가 섞이거나 한쪽 조회 실패가 가려지지 않게 하는 것이었습니다. 관리자 웹 화면은 제가 만들었고, 화면에 필요한 조회·로그인 확인·문의·AI 사용량 기능은 국가별 NestJS API에 모듈로 추가했습니다. 관리자 웹은 데이터베이스에 직접 연결하지 않고 API를 거쳐서만 데이터를 다룹니다.

02 해결 과정 DECISIONS

로그인은 한국 서버 한 곳에서 확인

관리자는 한국 서버에 한 번 로그인합니다. 미국 API는 받은 세션이 유효한지 요청마다 한국 서버에 확인한 뒤에만 응답합니다. 확인이 제때 끝나지 않거나 연결이 끊기면 통과시키지 않습니다. 비밀번호는 한국 서버에만 전달되고, 로그아웃은 두 나라에 함께 적용됩니다.

기록 조회는 읽기 전용 모듈로 분리

국가별 API에 조회만 하는 모듈을 따로 두었습니다. 한 번에 돌려주는 건수를 제한하고, 누가 무엇을 조회했는지 기록으로 남깁니다. 기존 수정·삭제 API 권한은 건드리지 않았습니다. 기록·구독 화면은 조회만 하고, 문의 화면에서만 처리 상태와 내부 메모를 바꿀 수 있습니다.

합친 목록과 숫자는 확인된 것만 표시

통합 범위에서는 두 나라 서버에 함께 조회한 뒤 ID 앞에 국가를 붙여 합칩니다. 한쪽 조회가 실패하거나 조회 중 전체 수가 바뀌면, 일부만 합친 목록 대신 오류를 보여 줍니다. 구독·매출 화면은 결제 금액 기록이 없으면 쿠폰이나 상품 가격으로 채우지 않고 ‘금액 기록 없음’으로 표시합니다. AI 비용은 측정된 토큰 수로만 계산한 예상치이고, 프롬프트·사진·답변은 저장하지 않습니다.

내보내기는 나눠서 이어 받기

엑셀과 사진 ZIP에는 건수와 용량 상한을 두고, 사진은 묶음으로 나눠 이어 받습니다. 브라우저 메모리를 넘기지 않기 위해서입니다. 묶음마다 성공·실패 목록을 남겨 빠진 파일을 확인할 수 있습니다.

03 결과 RESULT

가능해진 것 한국·미국 사용자 기록, 구독·쿠폰, 문의를 한 웹에서 조회하고, 기록은 엑셀로, 사진은 ZIP으로 내려받을 수 있습니다.

확인한 것 2026.10.11 배포 뒤 상태·접근 확인 17개 항목이 통과했습니다. 배포를 확인하는 점검이며, 사용자 시나리오 전체를 시험한 수치는 아닙니다.

배포 방식 관리자 웹 이미지만 따로 교체해 앱·API 배포와 엮이지 않고, 배포마다 이전 이미지를 남겨 되돌릴 수 있습니다.
