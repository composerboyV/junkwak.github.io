C++ HTTP/1.1 서버

소켓에서 CGI까지, HTTP 요청이 응답이 되는 과정을 구현하다

소켓과 비동기 I/O부터 CGI까지, 웹 요청을 처리하는 서버의 내부 흐름을 직접 구현했습니다.

C++98
Linux 소켓 기반 서버
epoll
non-blocking I/O
Python · PHP
CGI 실행 결과 연결

목차 CONTENTS

01 문제 02 결정 03 결과 04 근거

01 문제 PROBLEM

C++98과 Linux 환경에서 HTTP/1.1 서버를 직접 구현하는 팀 프로젝트였습니다. 네트워크 요청을 받고 응답하는 흐름에 외부 프로그램 실행 결과까지 연결해야 했습니다.

02 결정 DECISION

서버 구조와 비동기 I/O 흐름을 구성했습니다

부팀장으로 서버 구조 설계를 맡고 코드 리뷰에 참여했습니다. non-blocking 소켓과 epoll 기반 I/O로 네트워크 요청을 처리하는 구조를 구성했습니다.

CGI 실행 결과를 서버 응답에 연결했습니다

CGI 개발을 담당해 fork·exec·pipe로 Python·PHP 프로그램을 실행하고 그 결과를 서버 응답에 연결했습니다. 프로세스 실행과 입출력 연결을 코드로 다뤘습니다.

03 결과 RESULT

Linux 소켓 기반의 HTTP/1.1 서버와 Python·PHP CGI 실행 흐름을 구현했습니다. 네트워크 I/O와 프로세스 통신이 응답으로 이어지는 구조를 직접 다뤘습니다.

서버 구조 설계, CGI 개발과 코드 리뷰에 참여하며 네트워크 요청 처리와 외부 프로그램 실행을 팀의 서버 구조 안에 연결했습니다.
