01 과제와 역할 CONTEXT

C++98과 Linux 소켓으로 HTTP/1.1 서버를 만드는 팀 과제입니다. 정적 파일뿐 아니라 업로드·삭제와 외부 프로그램 실행 결과도 HTTP 응답으로 처리해야 했습니다.

부팀장을 맡아 Python·PHP를 실행하는 CGI와 예제 계산기 스크립트(calculator.py)를 직접 구현했습니다. 응답 처리에서는 CGI 요청인지 먼저 확인한 뒤 GET·POST·DELETE로 나누는 흐름을 설계했고, 이벤트 루프에는 종료 시그널을 받으면 연결을 정리하고 끝내는 처리를 더했습니다. 설정 파싱, 소켓·요청 파싱, 정적 파일·업로드·삭제, 에러 응답은 팀원이 구현했습니다.

02 CGI 구현 DECISIONS

요청 본문과 실행 결과를 파이프로 연결

CGI는 서버가 파일을 읽어 보내는 것과 달리, 별도 프로그램에 입력을 주고 출력을 받아야 합니다. 파이프 두 개와 fork로 입출력을 나누고, 자식 프로세스에서 dup2와 execve로 Python·PHP 인터프리터를 실행하도록 만들었습니다. POST 요청의 본문은 부모 프로세스가 자식의 표준 입력으로 전달합니다.

스크립트 출력을 HTTP 응답으로 변환

실행 결과를 그대로 보내면 CGI가 출력한 헤더와 실제 응답 본문을 구분하기 어렵습니다. 파이프로 받은 출력을 헤더와 본문으로 나눈 뒤, 본문 길이에 맞는 Content-Length를 붙여 서버의 기존 응답 전송 흐름에 연결했습니다.

03 요청 처리 구조 ARCHITECTURE

팀원이 만든 epoll 이벤트 루프가 연결을 받고, 요청 파싱과 라우팅을 거쳐 응답 분기로 넘어갑니다. 응답 분기는 흐름을 함께 설계했고, 그 안의 CGI 실행과 계산기 스크립트를 직접 구현했습니다. 아래의 ‘CGI 계산기 페이지 요청’ 예시에서 연결 수락부터 스크립트 실행·응답 전송까지 따라갈 수 있습니다.

04 구현 결과 RESULT

정적 파일·업로드·삭제를 처리하는 팀 서버에 Python·PHP 실행 결과를 반환하는 CGI 기능을 연결했습니다. 직접 작성한 calculator.py로 CGI가 출력한 HTML이 브라우저까지 전달되는 것을 확인할 수 있습니다. 직접 구현한 부분, 함께 작업한 부분, 팀원이 구현한 부분은 위 구성도에서 구분해 볼 수 있습니다.
