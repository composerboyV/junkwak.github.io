01 문제 PROBLEM

C++98과 Linux 환경에서 HTTP/1.1 서버를 처음부터 짜는 팀 프로젝트였어요. 요청·응답 흐름에 외부 프로그램 실행 결과까지 이어 붙여야 했습니다.

02 결정 DECISION

구조부터 그리고 들어갔어요

부팀장으로 서버 구조 설계를 맡고 리뷰에 깊이 들어갔습니다. non-blocking 소켓 + epoll 기반 I/O로 요청 처리 흐름을 깔았어요.

CGI는 fork·exec·pipe로

Python·PHP를 CGI로 실행하고 결과를 서버 응답에 연결했어요. 프로세스 띄우고 입출력 연결하는 걸 손으로 다뤄본 게 가장 큰 수확이었습니다.

03 결과 RESULT

Linux 소켓 위에 HTTP/1.1 서버를 올리고, CGI 실행 결과까지 응답으로 이었어요. 네트워크 I/O와 프로세스 통신이 어떻게 하나로 묶이는지 체감했습니다.
