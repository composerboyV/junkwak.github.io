01 지원 동기 MOTIVATION

AI 기능을 데모에서 끝내지 않고, 사람들이 매일 쓰는 서비스로 완성하는 일을 하고 싶습니다.

AICU에서 헬스케어 앱과 서버를 직접 만들고, 배포하고, 운영해 왔습니다. 미국에 출시한 스툴케어는 Apple 심사에서 의료 앱으로 오해받아 15번 반려됐습니다. Apple과 미팅해 기준을 확인하고 앱의 목적을 웰니스 앱으로 다시 정의한 끝에 출시할 수 있었고, 같은 앱에 회사의 첫 인앱 결제도 직접 구축했습니다. 이 일을 겪으며 기능을 잘 만드는 것만큼, 그 기능이 심사와 결제, 운영을 거쳐 사용자에게 끝까지 닿게 하는 일이 중요하다는 것을 배웠습니다.

지금은 같은 기준으로 LLM 기반 AI 에이전트를 만들고 있습니다. 모델이 그럴듯한 답을 내는 데서 멈추지 않고, 근거를 보여주며 사람이 확인할 수 있는 형태로 서비스 안에서 동작하게 하는 것이 목표입니다. 제가 가장 잘할 수 있고 앞으로 더 깊이 파고들고 싶은 일이라, 이런 일을 하는 팀에서 함께 만들어 가고 싶습니다.

02 직무 역량 COMPETENCE

에러가 보이지 않던 장애를 통신 로그를 직접 열어 찾아낸 것처럼, 저는 문제를 끝까지 추적해 서비스로 완성합니다.

2025년 12월, 피칼스캐너에서 결과를 조회하면 무한 로딩이 이어지다 앱이 꺼지는 장애가 있었습니다. 화면에는 에러가 드러나지 않아 증상만으로는 원인을 알 수 없었습니다. HTTP 클라이언트에 요청·응답 로그를 붙여 실제 통신을 확인했고, 분석 서버의 주소와 API 경로, 응답 JSON 구조가 모두 바뀌었는데 앱은 여전히 예전 텍스트 형식을 읽으려 했다는 것을 찾아냈습니다. 실제 응답에 맞춰 데이터 구조를 다시 설계하고, 응답이 비거나 오지 않을 때 사용자에게 안내하도록 예외 처리를 넣은 뒤 iOS·Android 기기에서 확인했습니다.

AI 에이전트는 믿고 쓸 수 있게 만듭니다. 42 Asia Hackathon 2026 in Tokyo에서 팀원들과 주일 프랑스상공회의소를 위한 AI 에이전트 4종을 42시간 만에 만들어 3위를 받았습니다. 저는 웹 플랫폼과 Azure 인프라, 채널 연동을 맡았고, 기업 매칭 제안이 직원이 확인한 문안 그대로만 나가도록 승인 흐름을 설계했습니다. 인사이트 에이전트의 첫 버전을 만들 때는 모델 출력을 정해진 형식으로만 받아 서버에서 한 번 더 검사했습니다. 팀 평가에서 상담 에이전트는 138번 실행 중 근거 없는 답을 1번만 했습니다.

규제와 보안 요구도 개발 단계에서 반영합니다. 중기부 TIPS 과제인 2등급 디지털의료기기 피칼스캐너-M의 환자용 앱과 의료진용 웹, API 서버를 만들고 AI 추론 서버까지 연결했습니다. 식약처 사이버보안 가이드라인의 35개 요구사항을 제품 구조에 맞춰 직접 시험했고, 적용 대상 30개 항목이 모두 적합함을 확인해 73쪽 시험보고서로 정리했습니다. 지금은 인허가 담당과 함께 임상시험계획 승인을 신청하고 있습니다.

03 성장 과정 GROWTH

작곡을 전공하고 음악교육 석사를 마친 뒤, 42 Gyeongsan에서 개발을 시작했습니다.

음악을 공부하며 익힌 창의적인 사고와 꾸준한 탐구 자세는 개발자로서 새로운 기술을 배우고 문제를 해결하는 과정에서도 이어지고 있습니다.

42 Gyeongsan에는 정해진 강의가 없었습니다. C로 셸을, C++로 HTTP 서버를 직접 구현하며 모르는 것은 동료에게 묻고, 동료 평가에서 서로의 코드를 설명하고 검토했습니다. 3D 렌더링 프로젝트에서는 팀장을 맡아 기능을 맞추고 진행을 챙겼고, 42 밴드에서는 드럼을 치며 밴드 운영을 총괄했습니다.

동료들과 함께 고민하고 문제를 해결하는 과정에서 많은 것을 배웠습니다. 지금은 그 경험을 바탕으로 기술적 선택에 이유를 갖고, 결과에 책임지는 개발자가 되고자 합니다.
